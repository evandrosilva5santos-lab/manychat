Botão de ação do painel e do builder.

- Variantes: `fx-btn-primary` (uma por área — Publicar, Atualizar, Nova automação), padrão (Editar), `fx-btn-danger` (Interromper, Excluir; contorno, nunca preenchido), `fx-btn-ghost` (Cancelar, ações terciárias). Tamanho `fx-btn-sm` dentro de nós e painéis.
- O consumidor fornece: o rótulo (verbo no infinitivo ou imperativo, sentence case), `disabled` e o handler.
- Não use dois primários lado a lado. Botões **dentro da DM** não são este componente — use `DmPreview`/`fx-dm-btn`.
