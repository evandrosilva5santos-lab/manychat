Selo de estado de uma automação, fluxo ou conexão.

- `fx-badge-live` = publicado e rodando; `fx-badge-draft` = rascunho; `fx-badge-stopped` = pausado/interrompido; `fx-badge-warn` = requer atenção (permissão Meta, token).
- Sempre com a palavra — a cor nunca carrega o significado sozinha. Texto em caixa alta pelo CSS; escreva o rótulo normal ("Ao vivo").
