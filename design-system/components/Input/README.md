Campo de texto e editor de mensagem.

- `fx-input` para uma linha; `fx-textarea` para o texto da DM, sempre com `fx-counter` (caracteres restantes; limite da API do Instagram: 1000).
- Palavras-chave de gatilho entram como `fx-chip` (removíveis). Variáveis/campos de sistema aparecem como `fx-var` (`{{first_name}}`) na fonte `mono`.
- Label acima do campo, em `fx-label`; nunca placeholder como label.
