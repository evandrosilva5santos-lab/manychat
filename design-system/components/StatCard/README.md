Métrica única do painel ou dos Insights de uma automação.

- O consumidor fornece rótulo, valor já formatado (pt-BR: `1.234`, `67%`) e, opcionalmente, unidade em `<small>` e link para o detalhe.
- 2 a 4 por linha, grade `fx-stats`. Não invente métricas decorativas: mostre só o que o motor realmente mede (envios, contatos, CTR, e-mails, telefones).
